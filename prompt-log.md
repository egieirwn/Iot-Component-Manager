## 📅 Log Prompt & Evaluasi

### Sesi 1: Merapikan Struktur Folder
*   **Prompt:** "Bagaimana cara memindahkan file HTML ke dalam folder pages/ menggunakan git mv agar history Git tidak hilang?"
*   **Hasil:** Berhasil memindahkan semua file HTML ke sub-folder (auth, inventory, borrowing, return) tanpa kehilangan history commit.
*   **Evaluasi:** Struktur proyek menjadi lebih rapi dan mudah dipahami oleh tim lain.

### Sesi 2: Membuat Tabel Komponen Dinamis
*   **Prompt:** "Buatkan fungsi JavaScript untuk merender data dari array ke dalam tabel HTML dan menambahkan fitur pencarian berdasarkan nama atau kategori."
*   **Hasil:** Fungsi `renderTabelKomponen()` dan `filterData()` berhasil dibuat dan diimplementasikan di `component.html`.
*   **Evaluasi:** Halaman web menjadi interaktif, tidak lagi statis. Data tidak perlu di-hardcode di HTML.

### Sesi 3: Persiapan Uji Validasi W3C
*   **Prompt:** "Apa saja error umum yang sering muncul saat validasi HTML5 di W3C Validator dan bagaimana cara memperbaikinya?"
*   **Hasil:** Memperbaiki atribut tag yang tidak lengkap dan memastikan semua elemen semantik (header, nav, main, footer) tertutup dengan benar.
*   **Evaluasi:** Seluruh file HTML berhasil lolos validasi tanpa error.
